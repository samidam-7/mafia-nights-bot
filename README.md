# 🕯️ Mafia Nights Bot

بوت Telegram للعبة المافيا باللغة العربية، مبني باستخدام Python و
`python-telegram-bot`.

## المزايا

- لعبة مافيا من 3 إلى 20 لاعبًا.
- أدوار: السفاح، كونان، الطبيب، الساحر، الحارس، الصياد، المهرج، الزعيم، المواطن.
- السفاح يحتفظ بآلية القتل الأصلية: آخر اختيار صحيح للسفاحين هو القرار المنفذ.
- الطبيب يحيي لاعبًا ميتًا مرة واحدة، ولا يحمي من القتل.
- قفل المشاركين داخل المجموعة أثناء الليل، ثم استعادة صلاحياتهم عند النهار.
- تصويت سري على الخاص مع حماية من الأزرار القديمة والتصويت المكرر.
- لعبة أعلام مستقلة.
- ملفات شخصية، مستويات، إنجازات وترتيب.
- حفظ JSON ذري وآمن نسبيًا لعملية تشغيل واحدة.
- لا يوجد أي Token داخل الكود.

## التشغيل

### 1. المتطلبات

Python 3.10 أو أحدث.

```bash
pip install -r requirements.txt
```

### 2. إعداد التوكن

انسخ `.env.example` إلى `.env` أو أضف المتغيرات إلى Replit Secrets.

المتغير الإلزامي:

```text
BOT_TOKEN=توكن_جديد_من_BotFather
```

لا تضع التوكن داخل ملفات Python أو ترفعه إلى GitHub.

على Replit، أضف `BOT_TOKEN` من Secrets ثم شغّل:

```bash
python main.py
```

### 3. صلاحيات البوت داخل المجموعة

لعمل قفل الليل كما يجب، اجعل البوت Administrator مع:

- Restrict members
- Delete messages (اختياري لتنظيف رسائل الجولة)
- Send messages

يجب على كل لاعب فتح البوت في الخاص وإرسال `/start` حتى تصله الأدوار
والتصويتات الخاصة.

## الأوامر

داخل المجموعة:

```text
المافيا
المافيا لعبة شرح
المافيا حالة
المافيا ترتيب
المافيا لعبة انهاء
اعلام
اعلام لعبة انهاء
```

في الخاص:

```text
/start
ملفي
احصائياتي
```

الزعيم يرد على رسالة لاعب بكلمة:

```text
طرد
```

## ملاحظات الأمان

- إذا ظهر توكن في سجل Git سابقًا، ألغِه من BotFather حتى لو حُذف من الملف.
- استخدم Replit Secrets أو متغيرات البيئة.
- لا ترفع ملف البيانات الحقيقي إلى GitHub.
- صلاحيات القفل تحتاج أن يكون البوت Administrator.
